# Programmes

| | POT: proof of technology | POC: proof of concept | POV: proof of value |
|---|---|---|---|
| Question | Does the stack fit our platform? | Does it work end to end? | Does it earn or save money? |
| Where | dev (synthetic data) | dev (synthetic data) | limited production pilot behind a flag, with a holdout group |
| Licence | free | free | commercial licence required |
| Exit | continue, continue with an ADR exception, or stop | move to POV, change scenario, or stop | scale, redesign, or close |

Each programme keeps `<round or scenario>/scope.md`, `criteria.yaml` and `evidence/` with the
command, exit code and head sha of every claim. In a round at most one programme produces code.
